Job Application Tracker, Capstone Milestone 1 (the data layer)
Shivani Shahi, INFO 5001, Fall 2026

1. You need Python 3, Jupyter and matplotlib (Anaconda has all three). Nothing else to install.
2. Open capstone_milestone1.ipynb and choose Restart and Run All. Run this file first.
3. It prints where each application stands, which open one to follow up on first, and which skills come up most, with one chart.
4. The last cell runs 7 SELF-CHECKs and prints "All 7 SELF-CHECKs passed".
5. tracker.py holds the functions. data/ holds steps.csv and details.csv.
6. output/ is made by the notebook: a saved copy of the steps, used to test saving.
7. Every path is built from BASE in tracker.py, so it runs from any folder.
